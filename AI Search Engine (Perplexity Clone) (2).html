Pasang NexusAI di Android

Perangkat Anda siap memasang aplikasi NexusAI secara instan (layar penuh tanpa bilah browser):

1. Install Langsung via Chrome Android (Tercepat)

  1. Unduh kode HTML ini lalu hosting gratis (misal ke GitHub Pages, Netlify Drop, atau Vercel).
  2. Buka tautannya di Google Chrome Android.
  3. Ketuk ikon titik tiga (⋮) di pojok kanan atas → pilih Tambahkan ke layar utama / Install aplikasi.
  4. Ikon NexusAI akan muncul di laci aplikasi Android Anda dan berjalan penuh layaknya aplikasi native.

2. Unduh sebagai File Installer (.APK)

Jika Anda membutuhkan file NexusAI.apk untuk dibagikan atau diinstal manual:

  1. Masukkan URL hosting aplikasi ini ke PWABuilder.com (gratis dari Microsoft), lalu klik Package for Stores → Android → Download APK.
  2. Atau bungkus file index.html ini secara lokal menggunakan Capacitor (npx cap add android).
